Welcome to **Mochi Math**, a cozy, pixel-inspired math playground where calculations feel a little less scary and a lot more adorable. ✿

Designed with soft colors, cute desktop aesthetics and interactive tools, Mochi Math turns your browser into a tiny workspace for exploring numbers and equations.

## 🎀 What's inside?

### 🧮 Calculator
Your everyday math buddy! Perform calculations in a simple, interactive interface without leaving your little desktop.

### 📈 Graph Studio
Give your equations a home and watch their curves bloom!

- Plot mathematical functions in real time.
- Explore multiple equations with different curve colors.
- Zoom in, zoom out and reset your graph.
- Experiment with functions like `x^2`, `sin(x)`, `cos(x)` and `sqrt(x)`.

*Tiny tip: trigonometric functions use radians.*

## Run it locally

Want to explore the code or make Mochi Math your own? Let's go! ♡

**1. Clone the repository**

```bash
git clone https://github.com/navmirajeev/mochi-math.git
cd mochi-math
```

**2. Install dependencies**

```bash
npm install
```

**3. Start the development server**

```bash
npm run dev
```

**4. Open your browser**

Visit [http://localhost:3000](http://localhost:3000) and let the maths begin! ✿

## 🧁 Project goals

Mochi Math is a little experiment in making useful tools feel delightful. The goal is to combine practical mathematical functionality with a friendly interface that makes people want to explore, experiment and learn.
